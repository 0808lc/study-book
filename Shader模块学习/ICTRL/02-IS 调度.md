# 02-IS 调度

> 上级：[[ICTRL/00-ICTRL 模块学习|ICTRL 模块学习]]

IS 负责指令发射与 wave 管理，功能包括：

**信息存储与依赖检查**
1. 保存每个 wave 的信息和指令控制字（control words）
2. 检查指令依赖关系
3. 指令 CC 字段处理

**特殊流程处理**
4. Instance 全零处理
5. 指令 End 处理
6. Dm-killing 处理
7. Ctrl 指令处理
8. Wait-bar 指令在依赖 ready 之前提前进入 NSR
9. 向量寄存器重配置（Vector register reconfig）
10. 调试模式 Trap 支持

**调度与发射**
11. 调度 wave 发射指令（Schedule wave for instruction issue）
12. 维护 wave 发射状态机（wave issue FSM）
13. Fop 指令 burst 拆分
14. 提取 wave PC 采样信息
15. Sqmma 发射控制

**流控（Throttle）**
16. 长延迟指令节流（Long latency instr throttle）
17. 每 wave 在途指令数量节流（Per-wave inflight instr throttle）

## Barrier workflow

1. 指令选择时，根据读屏障和写屏障设置 barrier counter
2. 指令发射至 VAC/NSR
3. VAC 或 NSR 读完所有源操作数后，清除读屏障
4. 流水线执行完成后，清除写屏障
5. CB 收集 vr/sl/shs/pred 写回并清除写屏障
6. barrier counter 向 IS 广播屏障状态，每个 wave 的 wait_mask 侦听 bc 状态并解除依赖关系

> 代码级细节（BC 检查信号、CC checker、发射流水）见 [[ICTRL/04-指令处理流程|04-指令处理流程]]。
